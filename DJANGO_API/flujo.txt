Esto es lo que tenemos
Listar usuarios	GET	/api/usuarios/	Devuelve todos los usuarios
Crear usuario	POST	/api/usuarios/	Crea un nuevo usuario
Recuperar detalle	GET	/api/usuarios/<id>/	Muestra un usuario específico
Actualizar	PUT	/api/usuarios/<id>/	Actualiza todos los campos de un usuario
Actualización parcial	PATCH	/api/usuarios/<id>/	Actualiza solo algunos campos del usuario
Eliminar	DELETE	/api/usuarios/<id>/	Borra un usuario
